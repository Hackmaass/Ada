# Features

## Overview

TalentGraph AI serves two primary personas: **Candidates** and **Recruiters**. Every feature is powered by ADA and grounded in evidence from the Professional Digital Twin.

---

## Candidate Features

### 1. Professional Digital Twin

A living, evolving model of professional capabilities.

- Auto-generated from connected evidence sources
- Continuously updated as new evidence arrives
- Skill graph with proficiency levels and confidence scores
- Project portfolio with complexity assessments
- Career trajectory with growth velocity metrics

### 2. AI Career Coach

Personalized career guidance powered by ADA.

- Role readiness assessment ("Am I ready for Senior Backend?")
- Skill gap analysis with specific recommendations
- "What-if" career simulations ("What if I learn Kubernetes?")
- Learning path recommendations based on target roles
- Progress tracking over time

### 3. Talent Analytics Dashboard

Visual representation of professional growth.

- Skill radar charts with temporal evolution
- Technology proficiency heatmaps
- Contribution activity timelines
- Growth velocity trends
- Peer benchmarking (anonymized)

### 4. AI Resume Builder

Generate evidence-backed resumes.

- Auto-populated from Digital Twin data
- Every skill claim linked to verifiable evidence
- Role-specific resume optimization
- ATS-friendly formatting
- Export to PDF/DOCX

### 5. Portfolio Generator

Automated professional portfolio creation.

- Curated project showcase with AI-written descriptions
- Code quality highlights and architecture diagrams
- Technology stack visualization
- Contribution metrics and impact indicators
- Shareable public link

### 6. AI Interview Preparation

Practice interviews tailored to the candidate's profile.

- Role-specific question generation based on Digital Twin gaps
- Real-time AI feedback on responses
- Technical depth evaluation
- Communication quality assessment
- Mock interview recordings with transcripts

---

## Recruiter Features

### 7. AI Hiring Copilot

Natural language candidate discovery and evaluation.

- Search candidates using plain English ("Find me a backend engineer with distributed systems experience and Go")
- Evidence-backed candidate rankings
- Automatic shortlist generation with rationale
- Follow-up questions to refine search ("Show me candidates who also have Kubernetes experience")

### 8. Explainable Candidate Reports

Transparent, evidence-backed candidate evaluations.

- Strengths and weaknesses analysis
- Evidence citations for every claim
- Role-fit assessment with percentage scores
- Risk indicators (skill gaps, verification failures)
- AI-generated interview questions tailored to each candidate

### 9. Candidate Comparison

Side-by-side candidate evaluation.

- Skill-by-skill comparison with evidence links
- Technology overlap and differentiation
- Growth trajectory comparison
- Code quality and architecture sophistication comparison
- Overall fit score breakdown

### 10. Hiring Pipeline

Basic pipeline management for the hiring workflow.

- Candidate stages (Discovered → Shortlisted → Interviewing → Offered → Hired)
- ADA-powered stage transition recommendations
- Notes and feedback per candidate per stage
- Team collaboration on candidate evaluations

### 11. Natural Language Search

Query the entire talent pool using natural language.

- Semantic search over Digital Twin data
- Filter by skills, experience, technologies, role readiness
- Fuzzy matching for similar skills and technologies
- Real-time results with relevance scoring

### 12. Hiring Analytics

Data-driven hiring insights.

- Pipeline conversion metrics
- Time-to-hire analytics
- Skill availability trends
- Candidate pool health indicators
- Hiring bias detection reports

---

## Shared Features

### 13. ADA Conversation Interface

Interactive chat with ADA for both personas.

- Context-aware responses grounded in Digital Twin data
- Evidence citations in every response
- Multi-turn conversation with memory
- Suggested follow-up questions
- Available throughout the platform

### 14. Evidence Management

Control over evidence sources and processing.

- Connect/disconnect evidence sources (GitHub, resumes, etc.)
- View processing status and results
- Request re-processing of evidence
- Export evidence data
